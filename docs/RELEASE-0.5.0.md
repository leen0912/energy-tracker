# 日迹 0.5.0：自然消耗与补充收敛

2026-09-19。本轮只调整本地电量模型和状态提示，保留 0.4 的视觉、输入与布局修复。不是医学测量，也没有健康数据或后台追踪。

## 变化

- 从最近感受出发，每小时自然消耗约 3 点；无需不断记录工作，也无需小程序后台常驻。打开时按经过的时间计算，前台按分钟刷新显示。
- 当天午夜或起点后 12 小时，先到者暂停本轮时间估算，显示「上次估计」。不追扣多天，也不自动回满。新的感受开启下一轮。
- 有明确时长的睡眠按区段排除；重叠区段合并，不重复排除。未记录睡眠无法被推断，补记后会重算起点之后的部分。
- 自然消耗最低到零；主动记录额外疲惫仍可透支。
- 补充按剩余空间收敛，普通事件不能把电量刷到 100。以 60 为起点、时间几乎不流逝时，四次默认补充约到 74；没有事件的两小时后约为 54。这些只是模型示例，不是对个人恢复能力的判断。
- 有时长的默认消耗抵扣同区段基础时间消耗，只追加剩余影响；主动选择的程度表示额外负担。名称、时长与名义影响仍完整存储，不要求用户挑分数。
- 数字变化少或不变时，花园仍响应记录。没有新增提醒。

## 旧数据

升级前先复制原始本机数据到 `.before-energy-v3`，然后把旧模型此刻的数值作为过渡起点，从更新后开始自然消耗。原始记录和点数不变。迁移只做一次；空间不足等失败会保留旧记录并阻止覆盖。

更新后可以按「此刻的感受」修正起点，但不会强制弹窗。v3 备份保留模型起点，恢复后不会重置计时；旧备份恢复时以恢复时刻建立过渡起点。旧程序不认识 v3，请勿直接降级覆盖。
