# 日迹 0.6.0：每天不同的窗边花园

2026-09-19。新增三套完整插花模板，不改变 0.5 电量计算、记录结构或隐私权限。

## 变化

- 珊瑚牡丹：粉珊瑚主花、白色小花与深浅绿叶。
- 蓝鸢尾：法式蓝鸢尾、奶白银莲花、少量金黄配花。
- 郁金香与虞美人：深浅红郁金香、杏色虞美人、白色配花。
- 原红色马蹄莲保留，共四套；每套四阶段、有无弟弟两个版本，共 32 张场景。
- 成熟花束更丰盛，保持城市楼景、黑窗框和窗台；等比留白为电量与文案让出空间，不裁切弟弟大爪子。

## 确定的日期规则

从 2026-09-19 起，依次牡丹、鸢尾、郁金香、马蹄莲，每四天循环。更早日期保持马蹄莲。不是每次打开随机换花；同一天的首页、日历缩略图、竖版/方版回响使用同一模板。

花束不区分经历好坏，也不绑定电量高低；记录数量只决定原有四个生长阶段。弟弟仅在当天存在陪伴记录时出现。删除或补记更新阶段和猫的状态，不更换当天模板。日期映射不需存储新字段，备份恢复后可重现；后续新增模板必须新增生效日期段，不能重排旧日期映射。
