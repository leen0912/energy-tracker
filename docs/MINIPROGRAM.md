## 这一版

- 主观感受建立起点；没有起点时不显示假定满电。
- 有起点后随时间缓慢消耗，睡眠区段排除、跨天暂停；越接近满电，事件补充越少。设置里可查看规则说明，当前感受可随时修正。
- 选择经历后确认保存；时长、感受程度、名称、时间与私人备注可补充；撤销、编辑、删除可用。
- 咖啡、奶茶、补剂默认中性；进食状态、饱腹与满足分开记录。没有催促和提醒。
- 每条经历都可进入花园；弟弟仅在有陪伴记录的日期出现。四阶段有序窗景通过双层柔边过渡呈现，同阶段有轻柔舒展反馈，可在设置中减少动效。没有独立花瓣或猫爪骨骼动画。
- 从 2026-09-19 起按日期轮换牡丹、鸢尾、郁金香、马蹄莲四套花园；更早日期保持原窗景。同一天三页使用同一套花，重新打开和编辑记录不换模板。新增 24 张本地场景，不需联网下载。
- 日历主屏只显示日子与当天摘要；点开再看明细。
- 回响支持竖版、1:1 方版、长名称完整分页；默认展示名称，私人备注不出现在图片中。
- 备份需主动复制，恢复需手动粘贴并确认；不自动读取剪贴板。

内部试用参数及旧记录迁移见 [PRD](../PRD.md)。这些是个人记账估算，不是身体测量。时长按截至发生时间的一段经历解释；请把睡眠时间改为实际醒来时刻来补记。

## 数据保护

数据仅存当前微信小程序本机空间。卸载、清理、换机前先备份。恢复会替换当前数据，不是合并；恢复前副本在 `daytrace.energy.wx.v1.before-restore`。损坏数据会锁住保存，避免空状态覆盖原始内容。备份包含私人备注，勿上传公开仓库。

原 v1 / v2 数据先保存到 `daytrace.energy.wx.v1.before-energy-v3`，再以升级时刻的旧模型现值建立 v3 过渡起点，不改旧记录、不追扣升级前时长。写入失败则保留原数据并阻止空状态覆盖。旧网页备份不能直接导入；升级后不要直接用旧版程序覆盖当前存储。每种记录最多 10000 条，达到限额会明确阻止新增。

持续计时按时间戳恢复，不依赖后台一直执行。超过七天的异常长计时，保存时按 10080 分钟上限处理；真实结束时刻保留，也可不留记录。新规则下跨过感受起点的区段只按起点之后的比例影响估算。

## 验证命令

```sh
npm ci
npx playwright install chromium
npm run mini:test
npm run mini:check
npm run mini:preview
```

`mini:check` 使用微信工具自带的 `wcc.exe / wcsc.exe`。其他电脑可通过 `WECHAT_DEVTOOLS_CLI` 指定 `cli.bat` 位置。`mini:preview` 使用编译后的真实模板和页面逻辑，但模拟微信 API；不能代替系统权限实测。

在开发者工具打开服务端口后，可运行：

```powershell
& 'D:\WC_devtools\微信web开发者工具\cli.bat' auto --project 'D:\番茄时钟\miniprogram' --port 44807 --auto-port 9420
npm run mini:smoke
```

截图与测试临时文件都在 `.local/wechat/`，不进入仓库。模拟器测试临时替换页面内存的保存方法，退出时重开页面恢复真实数据；不写入测试事件或调用相册/剪贴板授权。
