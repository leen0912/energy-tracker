# 需求如何变成日迹

## 演化过程

1. **拥有自己的番茄钟。** 起点是希望有一个不依赖订阅的个人工具。
2. **不必先知道要做多久。** 预设计时增加了开始的门槛，于是讨论开放式记录，让时钟负责后台归档。
3. **理解低电量的日子。** 加入睡眠、饮食、咖啡和感受，关注生活状态与恢复。
4. **回看与分享成为核心。** 一张愿意晒出去的总结图、一本愿意翻的日历，是持续使用的重要动机。
5. **沿用原来的日历。** 用户愿意在熟悉的日历中整理时间，产品负责读取、呈现与补充感受。
6. **从轻量网页开始。** 先体验回看与分享，再决定自动日历同步、提醒和 iPhone / Apple Watch 原生能力。
