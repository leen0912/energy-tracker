# 需求如何变成日迹

## 演化过程

1. **拥有自己的番茄钟。** 起点是希望有一个不依赖订阅的个人工具。
2. **不必先知道要做多久。** 预设计时增加了开始的门槛，于是讨论开放式记录，让时钟负责后台归档。
3. **理解低电量的日子。** 加入睡眠、饮食、咖啡和感受，关注生活状态与恢复。
4. **回看与分享成为核心。** 一张愿意晒出去的总结图、一本愿意翻的日历，是持续使用的重要动机。
5. **沿用原来的日历。** 用户愿意在熟悉的日历中整理时间，产品负责读取、呈现与补充感受。
6. **从轻量网页开始。** 先体验回看与分享，再决定自动日历同步、提醒和 iPhone / Apple Watch 原生能力。
7. **把电量放在中心。** 2026-09-15，用户进一步明确：睡眠、进食、弟弟带来的安慰是在充电；工作、人际支出和莫名的琐事可能在放电。产品转为个人电量显示器，番茄钟提供投入与恢复的记录入口，日历与分享负责回看。
8. **让生活长成花园。** 2026-09-16，先讨论成熟纸上花园与「都市暮色」，后收敛为早期时尚封面的纸白、墨色、朱红与青瓷绿。电量可以下降或透支，所有经历仍能进入花园；低电量不使用警报、枯萎或失败叙事。
9. **从效果图到真正能用。** 2026-09-17，补回城市、窗框与窗台，用四个完整构图阶段取代散乱叠加。按实际手机反馈修复花园突变、手动名称不可见和键盘后布局错位。模拟器与多尺寸回归已通过，实体 iPhone 的输入法体验继续验收。
