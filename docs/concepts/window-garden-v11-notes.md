# 窗景花园：落地修订

基于 V10 主视觉：城市楼景、墨色窗框、厚窗台、朱红主花、青瓷叶、蓝色配花，以及凯米尔色缅因弟弟的大爪子。

弃用随机定位的花束贴图。`window-garden-stages-v11.png` 是四行两列的生成原稿，左列无弟弟，右列有弟弟。`scripts/build-window-scenes.mjs` 按测量的画幅裁切、等比留白到 600×600，再压缩为 JPG；不拉伸猫或裁掉前爪。

- 0 条记录：小苗。
- 1 条记录：初长。
- 2–3 条记录：舒展。
- 4 条及以上：丰盛，继续记录仍保留所有数据。

0.4 保留旧图到新图加载，之后约 1.8 秒柔边揭示；同阶段使用一次轻柔舒展。不是每条记录独立新增花朵，也不是逐帧猫爪动画。所有方向和中性记录都计入阶段，弟弟只由真实陪伴事件决定。

主页面、日历缩略图、海报共用阶段派生规则。概念图中的“月份累计花园”和独立猫爪分镜不属于当前已实现能力。
