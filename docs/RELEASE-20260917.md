# 日迹 0.4.0：交互修复版

日期：2026-09-17。延续已有本机数据结构，不清空旧记录，不改变电量权重。

## 本轮修复

1. 花园不再直接替换背景后短闪。保留旧图，等新图加载完成，再进行 1.8 秒柔边向上揭示。连续记录合并到最新状态，切页停止动画；阶段不变时有一次轻柔舒展，减少动效设置仍生效。
2. 手动名称输入框使用明确深色文字、56px 高度、无纵向内边距。取消输入层的整体位移动画，避免原生输入框与变换容器错位。名称直接进入最近记录和日历详情，私人备注仍不公开。
3. 输入层按稳定窗口基准计算高度，键盘出现时明确缩减可滚动区域并定位当前输入，关闭后复原。使用 16px 及以上输入字体；主场景只随宽度定尺寸，不随键盘反复缩放。切换页签恢复顶部，底栏保留安全区。
4. 首页最新记录改为明确的展示字段，修复有记录却仍出现空提示的问题。

## 手机上试一下

1. 自己写一句，在第一行输入名称，保存后应立即在首页最近记录看到；无需复制到备注或回响页。
2. 连续开关输入层、切换电量/日历/回响至少三次，确认键盘收起后大小与起始一致；输入长备注可滚动到保存按钮。

花园仍使用四个完整构图阶段，不是逐根花茎、花瓣或猫爪的独立骨骼动画。没有以新增事件无上限堆叠图片。
