# 本地试用版 0.3 交付记录

日期：2026-09-16。本轮交付为可本地导入的微信小程序源代码，不是已经提交审核的线上版本。

后续修复已进入 [0.4.0](RELEASE-20260917.md)，以下为 0.3 阶段记录。

## 已完成

- 三页改为纸白、墨色、朱红、青瓷绿的都市花园视觉，弟弟使用浅凯米尔色缅因插画与大爪子。
- 首次「现在感受怎么样？」建立起点；未选择时不预设 100。旧数据迁移不改历史基准。
- 点选与确认保存分离，撤销、编辑、删除、开放计时接通；单次数值不展示。
- 可选时长与感受程度区分不同消耗；补记和跨起点的长经历避免重复叠加。
- 咖啡、奶茶、补剂入口默认中性；吃饭状态、时间、饱腹与满足可分别填写，没有饭点催促。
- 消耗、中性、补充都进入花园；即时数字过渡、四阶段窗景切换，可减少动效。0.3 的画面短淡入过于突兀，已在 0.4 修复。
- 日历移除收支表与重复明细，仅保留月历和选中日期摘要；明细在展开页。
- 回响默认展示记录名称，私人备注不导出；支持竖版、1:1 方版、完整长名称分页、预览及当前页保存。
- 本机存储异常保护、备份确认、手动粘贴恢复、图片生成失败重试与相册失败回退均保留。

## 隐私变化

没有新增敏感权限接口。保留以下两项既有调用：

1. `AlbumWriteOnly` / `wx.saveImageToPhotosAlbum`：用户主动保存当前回响 PNG 时写入相册，不读取已有照片。
2. `Clipboard` / `wx.setClipboardData`：用户确认导出完整备份时写入剪贴板，不读取原剪贴板；恢复只处理用户手动粘贴的文本。

新增或细化的主动填写内容：主观感受起点、持续分钟数、可选影响程度、进食状态、饱腹、满足感、饮品/补剂名称与份量文字，以及减少动效偏好。它们用于本地记录、估算与回顾，没有后台采集、业务上传或医学推断。分享仅使用日期、事件名称和由事件生成的图案，不导出私人备注与用量详情。

审核可直接填写的文案见 [隐私审核说明](WECHAT-PRIVACY-REVIEW.md)。后台运营主体、联系方式、保存期限、用户隐私同意配置仍需要账号负责人核对，本文不代替完整生效的隐私政策。
