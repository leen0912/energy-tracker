# 日迹：个人电量显示器

这是可直接导入微信开发者工具的原生小程序，不是网页发布目录。

1. 在微信开发者工具选择「导入项目」，选择本文件所在文件夹。
2. AppID 已写入 `project.config.json`，请使用有该小程序开发权限的微信登录。
3. 点击「编译」，再通过「预览」生成二维码，使用 iPhone 微信扫码。

无需构建 npm，也不需要域名、业务服务器或云开发环境。这里没有用户数据或账号密钥；AppID 是项目标识。

当前试用版为 0.5.0，支持感受起点、有界自然消耗、补充收敛、补充/消耗/中性记录、饮品与进食详情、开放计时、窗景花园、逐日回看、每日图片和本机备份。电量只是个人记账估算，不是身体测量。首次用「现在感受怎么样？」建立起点，不默认 100；自然消耗不制造透支，显式消耗可透支。分享默认展示事件名称，备注隐藏。记录不自动跨设备同步。

逻辑测试、微信编译、多尺寸交互与模拟器用于每版验收；实体 iPhone 键盘、字体放大、相册权限仍需确认。没有提交审核或正式发布。旧数据升级保留原始副本，更新后开始自然消耗，不追扣此前时间。

完整开发模块、数据边界及真机清单在仓库的 `docs/MINIPROGRAM.md`。图标授权见 `assets/LUCIDE-LICENSE.txt`。
