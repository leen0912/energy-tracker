# 日迹 · 生活的回响

一个从番茄钟逐渐变成的生活日历。回看时间、记下感受，生成可以收藏与分享的图片。

## 第一版可以体验什么

- 按月翻日历，点开某一天查看生活片段。
- 导入 `.ics` 日历文件，预览、调整分类、确认归档。
- 补记、修改、删除日常，记录睡眠、吃饭、咖啡和主观感受。
- 生成日/月分享图，切换浅色或深色，保存 PNG；支持时可调用系统分享。
- 导出备份、合并恢复，本机离线使用。
- 「看看示例」有独立的虚构记录，不影响自己的日历。

## 开发

推荐使用 Node.js 24；当前版本已在 Node.js 24.14.1 与 Windows 上验证。
获取仓库后，在项目目录打开终端：

```sh
npm ci
npm run dev
```

生产构建与检查：

```sh
npm run build
npm test
npm run check:pwa
```

浏览器测试首次使用需执行 `npx playwright install chromium`。Linux 环境可使用 `npx playwright install --with-deps chromium` 安装浏览器及系统依赖。`check:pwa` 启动临时生产预览，验证离线打开后自动关闭。

发布产物在 `dist/`，可部署到静态 HTTPS 站点根目录。开发服务器只是本机预览，不是已经发布的外网网址；iPhone 主屏幕安装和系统分享仍需在真实设备验收。

## 当前边界

数据保存在当前浏览器，清理浏览器数据前请备份；不同设备之间不自动同步。日历导入是文件快照，尚未接实时日历授权。重新导入同一日程可更新；原日历中删除或取消的既有片段需在日迹中移除。

精力来自你自己的感受。网页内饭点提示、主观记录均已实现；后台定时推送、AI 聊天、Apple Watch 原生应用与健康数据读取尚未实现。
