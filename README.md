# 日迹 · 生活的回响

一个从番茄钟演化出的个人精力记录产品。

**2026-09-15 方向更新：个人电量显示器。** 用睡眠、进食、宠物陪伴等充电记录，以及工作、人际支出、琐事等放电记录，理解当前余量与每日充放电收支。新版产品方案见 [PRD](./PRD.md)，评分不是身体的客观测量。

仓库现在包含两个独立客户端：`src/` 是原有网页日历原型；`miniprogram/` 是新增的微信原生电量小程序。二者不共用存储，也没有自动迁移。

## 微信小程序首版

已实现首次感受起点、选择后确认记录、可选时长与程度、进食详情、中性咖啡/奶茶/补剂、编辑撤销、开放计时、极简日历、动态花园、竖版/方版分享和本机备份恢复。首次不再默认 100；单次分数不展示，备注不进入分享图。弟弟采用真实凯米尔色缅因的插画形象。

在微信开发者工具中导入 **`miniprogram/`**，不要导入整个仓库。项目已配置现有 AppID，不需要安装小程序 npm 依赖，也不需要域名或业务服务器。本地逻辑测试、微信模板/样式编译、多尺寸交互测试和微信模拟器实际图片生成已验证。iPhone 真机首次隐私授权、相册许可和后台恢复仍需确认，尚未代替用户上传或提交审核。

详细步骤及验收清单见 [小程序导入与试用说明](./docs/MINIPROGRAM.md)。

当前本地试用版为 **0.4.0**，重点修复花园突变、手动输入不可见、手机反复操作布局不稳；验证范围和限制见 [2026-09-17 修复记录](./docs/RELEASE-20260917.md)。

## 原有网页可以体验什么

- 按月翻日历，点开某一天查看生活片段。
- 导入 `.ics` 日历文件，预览、调整分类、确认归档。
- 补记、修改、删除日常，记录睡眠、吃饭、咖啡和主观感受。
- 生成日/月分享图，切换浅色或深色，保存 PNG；支持时可调用系统分享。
- 导出备份、合并恢复，本机离线使用。
- 「看看示例」有独立的虚构记录，不影响自己的日历。

## 开发

推荐使用 Node.js 24；当前版本已在 Node.js 24.14.1 与 Windows 上验证。
获取仓库后，在项目目录打开终端：

```sh
npm ci
npm run dev
```

生产构建与检查：

```sh
npm run build
npm test
npm run check:pwa
```

浏览器测试首次使用需执行 `npx playwright install chromium`。Linux 环境可使用 `npx playwright install --with-deps chromium` 安装浏览器及系统依赖。`check:pwa` 启动临时生产预览，验证离线打开后自动关闭。

发布产物在 `dist/`，可部署到静态 HTTPS 站点根目录。开发服务器只是本机预览，不是已经发布的外网网址；iPhone 主屏幕安装和系统分享仍需在真实设备验收。

## 当前边界

数据保存在当前浏览器，清理浏览器数据前请备份；不同设备之间不自动同步。日历导入是文件快照，尚未接实时日历授权。重新导入同一日程可更新；原日历中删除或取消的既有片段需在日迹中移除。

精力来自你自己的感受。网页内饭点提示、主观记录均已实现；后台定时推送、AI 聊天、Apple Watch 原生应用与健康数据读取尚未实现。
